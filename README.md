# QA

This repo tracks issues assigned to PhET's QA team and the relative priority of these issues.

Everything other than the [issues](https://github.com/phetsims/qa/issues) has moved to PhET's monorepo, which is not
publicly available at this time:

- [QA issue templates](https://github.com/phetsims/totality/tree/main/qa/issue-templates). Copy and paste one into a
  new issue in this repo.
- [QA Book](https://github.com/phetsims/totality/blob/main/qa/documentation/qa-book.md)
- [Accessibility bugs and behaviors](https://github.com/phetsims/totality/blob/main/qa/documentation/accessibility-bugs-and-behaviors.md)
